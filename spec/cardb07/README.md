Opaque edge fields use `LinkMetadata.nativeExtensions`: keys are exact
`beads.<field>` names, and values are UTF-8 JSON **token text in strings**. This
preserves object spacing, escaped strings and numeric spellings through outer
JSON encoding. Absence is an absent key, null is `"null"`, and an empty string is
`"\"\""`. Represented identity fields cannot be overridden. Opaque values do not
supply a predicate, thread mapping, identity allocation or scheduling meaning.
Omitted keys preserve previous values. Typed gate metadata remains independent.

The archive reader captures raw source tokens at every record decode, including
records nested in source history, before map decoding. Unknown
future edge columns are retained without relaxing required existing columns.
Imported hierarchy metadata stays on the single parent representation rather
than introducing another generic relationship. Reverse validates token/source
correspondence and writes raw tokens without re-encoding them; the existing
edge identity envelope retains the native metadata token as its payload.
Authored unknown-field/malformed cases remain authored controls. Actual native
thread observations are supplied separately to the same import/reverse path.
Existing immutable source mirrors and archive digests remain authoritative.
