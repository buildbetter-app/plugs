# B07 public edge vocabulary and opaque native fields

Completion requires new exact-head source review, actual canonical native
observations and named memory/SQLite/PostgreSQL public counterparts, followed by
an unfiltered whole gate. Source, authored archive controls, public native
recordings, historical provenance, hosted checks and full-card qualification are
separate. No previous B07 receipt is reused.

`public_edges_test` exercises the real composed byte-RPC service and Writer on
all three drivers. It retains complete records, versions, changesets, derived
rows, checkpoints and caller receipts. SQL tests physically close and reopen the
store. Owned PostgreSQL startup/version/port and checked cleanup are retained.
The memory mixed-plane capability refusal is a literal open parity gap; it is
not a positive mixed-plane outcome. Successful mixed-plane `tx.apply` controls
use normal SQL composition and the existing admitted source runtime on all
three engines. Their actual outcomes must be delivered separately; the source
runtime does not establish normal memory-provider parity.

`public_native_edges_test` explicitly selects the card's canonical operational
recording. It reuses the unchanged B20 build source export and pinned public
native Dolt runtime. Two independent public workspaces retain exact native
source/binary/request identity, raw stdout/stderr/exits, readonly SQL images,
ready membership and actual command outcomes. The supported batch route tests
opaque kinds; the narrower standalone refusal is a separate observation. Graph
creation exercises actual thread preservation/replacement and mixed-plane
rollback. Public JSONL import exercises native metadata equality. Reference
production code and its semantics are unchanged.

Opaque edge fields use `LinkMetadata.nativeExtensions`: keys are exact
`beads.<field>` names, and values are UTF-8 JSON **token text in strings**. This
preserves object spacing, escaped strings and numeric spellings through outer
JSON encoding. Absence is an absent key, null is `"null"`, and an empty string is
`"\"\""`. Represented identity fields cannot be overridden. Opaque values do not
supply a predicate, thread mapping, identity allocation or scheduling meaning.
Omitted keys preserve previous values. Typed gate metadata remains independent.

The archive reader captures raw source tokens at every record decode, including
records nested in source history, before map decoding. Unknown
future edge columns are retained without relaxing required existing columns.
Imported hierarchy metadata stays on the single parent representation rather
than introducing another generic relationship. Reverse validates token/source
correspondence and writes raw tokens without re-encoding them; the existing
edge identity envelope retains the native metadata token as its payload.
Authored unknown-field/malformed cases remain authored controls. Actual native
thread observations are supplied separately to the same import/reverse path.
Existing immutable source mirrors and archive digests remain authoritative.

Named controls:

- `TestB07PublicVocabularyIdempotencyAndGuards`: 19 fixed kinds, opaque and
  whitespace-sensitive kinds, byte limits, no-op/replay/retype conservation,
  complete ready sets, ordinary guards, external targets and typed metadata.
- `TestB07OpaqueEdgeTokensAcrossStores`: byte fidelity, unknown fields,
  null/empty distinction, malformed atomic refusal, predicate inertness,
  source import and independent reverse output, with SQL reopen.
- `TestB07PublicMixedPlaneIdentity`: actual normal-composition capability,
  SQL mixed endpoint identity, namespace-receipt-only no-op, replay, retype,
  successful mixed batch, reopen/replay, late retype refusal, malformed batch
  refusal and both-plane conservation.
- `TestB07ImportedOpaqueWaitsReadiness`: an explicitly authored closed spawner
  with an open child retains legacy waits readiness after import, opaque-only
  edits and SQL reopen; an explicit waits predicate is the negative control.
- `TestB07SourcePlaneOpaqueEdgeRoundTrip` in converterroundtrip: future escaped,
  numeric and object tokens traverse the existing admitted source runtime on
  all three stores, including successful mixed writes, reopen/replay, opaque
  reverse and later retype/malformed mixed-batch refusal.
- `TestB07CanonicalNativeEdgeCounterparts`: same-run canonical source-built
  twins plus the three actual public counterparts above.

Both author gates use the seven canonical controls plus
`--lockfile_mode=error`. The native target is manual and must be explicitly
selected in focus. The whole-selected public target remains unfiltered in
literal `test //...`. Raw native values are retained before any declared
comparison; B02 adopted outcome differences never imply raw equality.

`BAZELISK_HOME`, `BAZELISK_VERIFY_SHA256`, `GITHUB_RUN_ID`, `GITHUB_RUN_ATTEMPT`,
`GITHUB_SHA` and `GITHUB_WORKFLOW_REF` with `--test_env=<name>`, and supplies
`--test_env=PLUG_B07_REQUEST_SHA=<exact candidate>`. These are the unchanged
shared builder's existing runner contract; no caller checkout-root override is
used.
