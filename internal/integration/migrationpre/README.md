# Connected migration validating-pre composition

This package connects the protected ontology source, real complete bead-row
enumeration, compiler, migration planner and native `pluginhost` validating
callbacks through the read-only `ontologyops.Service` boundary. The callback
receives detached before/after row images and a pinned driver snapshot; it has
no write handle or protected-apply path.

The acceptance target proves overlay-row selection, actual native rejection and
exact grandfather disposition, source/row/binding invalidation, detached
callback images, the 5,000-row boundary, cancellation and plugin-owned field
refusal. The 5,001-row case refuses before invoking a callback. The package
uses the memory driver for connected behavior and does not claim durable
persistence, protected apply or production cutover. The overlay case uses the
existing in-process JSON-RPC bytes; this package adds no network listener or
RPC binding.
